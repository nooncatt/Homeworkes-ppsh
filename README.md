# Homeworkes-ppsh

Репозиторий со студенческими домашними заданиями и учебными мини-проектами по Python.

## Что внутри

* **Отдельные скрипты** (`21.py` … `34.py`) — решения небольших задач.
* **Папка `Pytest_hw/`** — упражнения по написанию тестов на `pytest`.
* **Папка `Flask/`** — простые веб-приложения на Flask.
* **Папка `API/`** — заготовки под учебные REST-сервисы.
* **Прочие файлы** (`.ipynb`, `.csv`, `.pptx`, `index.html`) — материалы и вспомогательные данные к занятиям.
